# BioLab: Containment Breach

🧟 **3D Horror Game** — браузерная хоррор-игра в стиле Resident Evil

## Как играть

### Запуск
```bash
# Вариант 1: Простой HTTP сервер (рекомендуется)
cd ~/Downloads/3dgame
python3 -m http.server 8080
# Открыть http://localhost:8080

# Вариант 2: Открыть index.html напрямую
# (некоторые браузеры могут блокировать ES модули через file://)
```

### Управление (ПК)
| Клавиша | Действие |
|---------|----------|
| **W/A/S/D** | Движение |
| **Мышь** | Осмотр |
| **Shift** | Бег |
| **F** | Фонарик вкл/выкл |
| **E** | Взаимодействие |
| **Клик** | Захват мыши |

### Управление (Мобильный)
- **Левый джойстик** — движение
- **Правая область** — осмотр (свайп)
- **USE** — взаимодействие
- **LIGHT** — фонарик
- **RUN** — бег

## Цель игры

1. Найти **3 ключ-карты**: 🔴 Красную, 🔵 Синюю, 🟢 Зелёную
2. Избегать монстров (или погибнуть!)
3. Открыть **выход** (золотая дверь) со всеми картами
4. **ВЫЖИТЬ**

## Особенности

- 🔦 Динамическое освещение с фонариком
- 👾 Два типа врагов: Crawler (быстрый) и Stalker (медленный но опасный)
- 🚪 Цветные двери требуют ключ-карты
- 💀 Jump scares!
- 🗺️ Мини-карта
- 🎵 Процедурный звук (Web Audio API)
- 📱 Работает на мобильных!

## Технологии

- **Three.js** — 3D рендеринг
- **PointerLockControls** — управление от первого лица
- **Web Audio API** — звуки без внешних файлов
- **ES Modules** — современный JavaScript
